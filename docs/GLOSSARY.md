# Glossary

Trade and language terms that appear in calls and in the code.

## Units

| Term | Bangla | Meaning |
|---|---|---|
| Dozen | ডজন | 12 pieces. The default wholesale unit. |
| Hali | হালি | 4 pieces. Common for small counts. |
| Piece | পিস | Single unit. Storage unit in the DB. |
| Gross | গ্রোস | 144 pieces (12 dozen). Rare but appears. |
| Thaan / Than | থান | A full roll or bolt of fabric. |

## Trade

| Term | Meaning |
|---|---|
| Baki | বাকি — credit / buying on account. Escalate, never grant. |
| Dam | দাম — price. Negotiation attempts escalate. |
| Maal | মাল — goods, stock. |
| Lot | A production batch. Colour can vary between lots of the same SKU. |
| Chalan | চালান — delivery challan / dispatch note. |
| Islampur, New Market | Dhaka wholesale garment markets. Common caller locations. |

## System

| Term | Meaning |
|---|---|
| DRAFT | Order created by the agent. Not real yet. |
| CONFIRMED | Human-approved. Triggers the final offer email. |
| Final offer | The itemised, priced quotation emailed after confirmation. |
| Golden set | `tests/fixtures/banglish-utterances.json` — the regression suite. |
